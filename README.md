# Easy Plant App – Indoor Plants Marketplace

**Easy Plant App** is a beautiful and responsive platform where users can explore, discover, and book the best indoor plants for their home or office. Perfect blend of modern UI and smooth booking experience.

[**Live Demo**](https://easyplant-team-msh.netlify.app/)  

<br/>

## Screenshot

![Easy Plant App](https://raw.githubusercontent.com/Md-Shajib-Hossain/easy-plant-app/main/src/assets/Screenshot%202025-11-19%20113902.png)

<br/>

## Features

- Fully responsive design (mobile + tablet + desktop)  
- Browse plants by category, price, light requirement  
- Plant details with care tips & reviews  
- Booking/Appointment system  
- Add to wishlist / favorites  
- Smooth animations with Framer Motion  
- Toast notifications  
- Firebase authentication & data storage  


<br/>

## Tech Stack

<p align="center">
  <img src="https://skillicons.dev/icons?i=react,vite,tailwind,firebase,javascript,daisyui,git,github,vscode,netlify" />

- **React 19** + **Vite** – Lightning fast development
- **Tailwind CSS** + **DaisyUI** – Beautiful & customizable components
- **Firebase** – Authentication, Firestore database & hosting
- **Framer Motion** – Smooth page transitions & animations
- **React Router v7** – Client-side routing
- **React Hot Toast** – Elegant notifications
- **Lucide React** – Modern icon set

## Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/Md-Shajib-Hossain/easy-plant-app.git

# Enter the project folder
cd easy-plant-app

# Install dependencies
npm install
# or
yarn

# Start development server
npm run dev
